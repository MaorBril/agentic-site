The $25 Challenge

What can an agent build when the meter stops at $25?

Enter on GitHub →

Rules

  1. Set your cap before you start: gremlord budget set --daily 25.
  2. Build anything real: a tool, a fix, a feature, a demo. Vibe-coding your landing page doesn't count — it has to do something.
  3. Enter by replying to the pinned "The $25 Challenge" discussion with: what you built (one paragraph), a link to the repo or demo, and your gremlord cost --receipt output pasted in full as the receipt.
  4. Used a passthrough profile or subscription-billed CLI delegation (Codex/Grok under your own ChatGPT/SuperGrok login) for any part of the build? Those runs show $0 or don't appear in gremlord cost at all. Disclose it in your entry — it doesn't disqualify you, but judges factor it in.
  5. Used a local/self-hosted model (Ollama, vLLM, etc.)? Those don't have a metered API price either, so gremlord cost won't show real spend for them. Price them by fixed hardware rate × active runtime instead, and add it to your tracked total:
    Tier Hardware Rate
    1 Laptop / mini PC, base Apple M-series, GPU ≤12GB $0.10/hr
    2 High-memory workstation, M Pro/Max, Ryzen AI Max $0.25/hr
    3 One 16–24GB consumer GPU + host $0.35/hr
    4 Two consumer GPUs or one 48GB pro GPU + host $0.70/hr
    5 Datacenter accelerator actual rental rate, else $3/hr
    Match your model to a tier: 4–12B Q4 → tier 1. gpt-oss 20B or Qwen3-30B-A3B → tier 2 or a 24GB GPU (tier 3). Dense 32B → tier 2 or tier 3. 70B Q4 → tier 4 (64GB+ unified memory or two GPUs). Submit your gremlord receipt, your hardware tier, and your active runtime alongside it — tier rate × runtime counts toward the $25 cap.
  6. Honor system on receipts. A faked log to win a README mention is a sad life.
  7. One entry per person. Entries close 7 days after the announcement post.

How to enter

1

Install gremlord

One command, see the README for details.

2

Set your $25 cap

gremlord budget set --daily 25 — the router refuses the next request once you hit it.

3

Print your receipt

gremlord cost --receipt — add --session <id> if it wasn't the latest.

4

Reply with your build + receipt

Reply to the pinned Discussion with your build, that receipt pasted in full, a disclosure line for any passthrough/subscription CLI delegation, and your hardware tier + active runtime for any local models. 

# install
❯ curl -fsSL https://raw.githubusercontent.com/gremlord/gremlord/main/install.sh | sh

❯ gremlord budget set --daily 25

# your receipt — paste this in full
❯ gremlord cost --receipt
