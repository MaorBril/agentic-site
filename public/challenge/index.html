The $25 Challenge

What can an agent build when the meter stops at $25?

Enter on GitHub →

Rules

  1. Set your cap before you start: gremlord budget set --daily 25.
  2. Build anything real — a tool, a fix, a feature, a demo. Vibe-coding your landing page doesn't count — it has to do something.
  3. Enter by replying to the pinned "The $25 Challenge" discussion with: what you built (one paragraph), a link to the repo or demo, and your gremlord cost --receipt output pasted in full as the receipt.
  4. Honor system on receipts. A faked log to win a README mention is a sad life.
  5. One entry per person. Entries close 7 days after the announcement post.

How to enter

1

Install gremlord

One command, see the README for details.

2

Set your $25 cap

gremlord budget set --daily 25 — the router refuses the next request once you hit it.

3

Reply with your build + cost log

Reply to the pinned Discussion with what you built, a link, and the full output of gremlord cost --receipt as your receipt.
